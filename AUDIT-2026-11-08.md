## 1. Security — fix before anything else

The repo `Knight-Logics/Whistle-Stop` is public.

- The shared staff password was written in plain text in `site/README.md` (now removed, still in git history). Owner, editor and staff share it.
- Its unsalted SHA-256 (`400c2268…`) is in public `site/data/site.json` (`admin.passwordHash`, `admin.users[]`), because `config-store.js` checks login in the browser. The browser also stores the plain password in sessionStorage (`pwd`).
- `knight-command/whistle-stop-campaigns.js` `authorizeAdmin()` (lines 102–111) accepts the hash itself (`adminSessionHash` body field or `X-WS-Admin-Hash` header) when it equals `WS_ADMIN_PASSWORD_HASH`. Anyone with `site.json` can call staff campaign routes (private signups, verified leads, Zoho sends).
- The content publisher (`https://knightlogics.com/api/whistle-stop-content`) reportedly uses the same scheme (July audit); its code is not in this repo — unconfirmed.
- Social Host bridge (`ws-social.knightlogics.com` → `bridge-server.js` on Nick's PC) accepts the plain password, so anyone can post through the logged-in Knight Logics demo sessions.
- Unsubscribe signing secret falls back to `WS_ADMIN_PASSWORD_HASH` when `WS_CAMPAIGN_UNSUBSCRIBE_SECRET` is unset (line 499) → forgeable tokens.
- `site/downloads/*.zip` (3 Social Host packages) publish Growth System / OutreachEngine scripts (bridge server, tunnel setup, tunnel ID, hostnames). No secret values found in the v2 zip, but this breaks the rule that Growth System code stays off public GitHub.

Fix order (all need Nick's approval):

1. Rotate `WS_ADMIN_PASSWORD_HASH` (Vercel + bridge PC); stop the Whistle Stop bridge or its tunnel route.
2. Set `WS_CAMPAIGN_UNSUBSCRIBE_SECRET` to its own random value.
3. Move login server-side: Cloudflare Access on `/admin*` + admin APIs (preferred, see §3), or a Knight Command `/login` route returning a signed 12-hour token. Then remove `admin` users/hashes from `site.json`, stop accepting raw hashes, stop storing `pwd`.
4. Delete `site/downloads/*.zip`; distribute the host package privately if still needed.
