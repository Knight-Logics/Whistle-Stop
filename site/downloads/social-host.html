Whistle Stop Social Host

This is a one-time shared-host setup, not an installation for every device. Choose one designated Windows PC that stays awake. Once it is online, authorized staff can use the Social Poster from any phone, tablet, laptop, or desktop through the browser.

What this enables

  • With the one shared host running: the full Facebook, X, LinkedIn, Nextdoor, and Google Business Profile workflow is available from every admin device
  • Without the host (cloud fallback): Facebook Page, X, and Google Business Profile can remain available while browser-session channels wait for the host

Demo posts go to Knight Logics accounts only.

Download & run

  1. On the designated Windows host PC, download whistle-stop-social-host-2026-07-13-v2.zip
  2. Unzip (e.g. Desktop)
  3. Right-click START-HOST.ps1 → Run with PowerShell
  4. Keep bridge + tunnel windows open
  5. Open admin on any device → Social Poster. No package is installed on phones, tablets, or other staff computers.
