Whistle Stop Social Host

Owner and editor accounts are prompted to download this package after login when a Playwright host is not already online. Run it on any Windows PC that stays awake. Other devices only need the browser.

What this enables

  • With host running: LinkedIn, Nextdoor, Facebook community groups (Playwright)
  • Without host (cloud only): Facebook Page, X, Google Business Profile

Demo posts go to Knight Logics accounts only.

Download & run

  1. Download whistle-stop-social-host-2026-07-13.zip
  2. Unzip (e.g. Desktop)
  3. Right-click START-HOST.ps1 → Run with PowerShell
  4. Keep bridge + tunnel windows open
  5. Open admin on any device → Social Poster
