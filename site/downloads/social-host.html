Whistle Stop Social Host

Run this on any Windows PC that stays awake (home desktop or presentation laptop). Other devices only need the browser admin — they do not install anything.

What this enables

  • With host running: LinkedIn, Nextdoor, Facebook community groups (Playwright)
  • Without host (cloud only): Facebook Page, X, Google Business Profile

Demo posts go to Knight Logics accounts only — not Knight Group, Screen Team, or Faith Works.

Requirements

  • Windows PC with the Whistle-Stop repo (and Knight Logics Growth System for Playwright)
  • Internet + ability to run PowerShell
  • Keep the bridge and tunnel windows open during the pitch

Start the host

  1. Open PowerShell in the Whistle-Stop folder
  2. Run: .\START-HOST.ps1
  3. Wait until local bridge, tunnel, and cloud checks are green
  4. On any laptop, open admin.html, sign in, Social Poster → post
Download START-HOST.ps1 Repo on GitHub Open staff admin

Always-on main PC

For a desk PC that stays on: run START-MAIN-PC-HOST.ps1 once and register the Task Scheduler jobs under Social\WhistleStop\deploy\install-all.ps1. Then any staff laptop can use Graph + Playwright without carrying a flash drive.

If guest WiFi blocks the tunnel

Facebook Page / X / GBP still work via knightlogics.com. For LinkedIn/Nextdoor, run the host on a machine that can reach Cloudflare (often phone hotspot or the venue’s staff network), or rely on the main PC at home if Vercel reports remoteBridge: true.
